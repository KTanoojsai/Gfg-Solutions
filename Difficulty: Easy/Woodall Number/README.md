<h2><a href="https://www.geeksforgeeks.org/problems/woodall-number2349/1?page=8">Woodall Number</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a positive integer <strong>n</strong>, find if it is a Woodall number.&nbsp; </span><span style="font-size: 18px;">A Woodall number is a positive integer that can be expressed in the form <strong>k * 2</strong></span><strong><sup>k </sup><span style="font-size: 18px;">- 1 </span></strong><span style="font-size: 18px;">for some positive integer <strong>k</strong>.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 383
<strong>Output:</strong> true
<strong>Explanation:</strong> <br></span><span style="font-size: 18px;">383 can be expressed as 6 × 2? − 1 = 6 × 64 − 1 = 384 − 1 = 383. <br>Hence, it is a Woodall number.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 200
<strong>Output:</strong> false
<strong>Explanation:</strong> <br>There is no positive integer k such that k × 2^k − 1 = 200. <br>Therefore, 200 is not a Woodall number.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematical</code>&nbsp;
