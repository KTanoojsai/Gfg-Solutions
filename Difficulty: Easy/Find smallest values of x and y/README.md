<h2><a href="https://www.geeksforgeeks.org/problems/find-smallest-values-of-x-and-y-such-that-ax-by-01433/1?page=8">Find smallest values of x and y</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given two positive integers <strong>a</strong> and <strong>b</strong>, representing the coefficients in the equation <strong>ax - by = 0</strong>, find the smallest positive integers <strong>x</strong> and <strong>y</strong> that satisfy the equation.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> a = 25, b = 35
<strong>Output:</strong> [7, 5]
<strong>Explanation:</strong> 25*7 - 35*5 = 0. And x = 7 and y = 5 are the least possible values of x and y to get the equation solved.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> a = 3, b = 7
<strong>Output:</strong> [7, 3]
<strong>Explanation:</strong> For this case x = 7 and y = 3 are the least values of x and y to satisfy the equation.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ a, b ≤ 10<sup>4<br></sup>n = max(a, b)</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematical</code>&nbsp;
