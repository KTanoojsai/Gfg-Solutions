<h2><a href="https://www.geeksforgeeks.org/problems/seeds-of-a-number5156/1?page=9">Seeds of a number</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">A seed of a number <strong>n</strong>, is a number x such that multiplication of x with its digits is equal to n. </span></p>
<p><span style="font-size: 18px;">Return all seeds of a given number n in ascending order. x should not be equal to n. If no seed exists, then return {-1}.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 138
<strong>Output:</strong> [23]
<strong>Explanation:</strong> 23 is a seed of 138 because 23*2*3 = 138.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 3
<strong>Output:</strong> [-1]
<strong>Explanation:</strong> There is no seed of 3.</span></pre>
