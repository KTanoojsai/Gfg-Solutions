<h2><a href="https://www.geeksforgeeks.org/problems/fibonacci-expression3939/1?page=8">Fibonacci Expression</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a number <strong>n, </strong>evaluate the following expression.&nbsp;f(n-1)*f(n+1) - f(n)*f(n) where f(n) is the n-th&nbsp;<a href="http://www.geeksforgeeks.org/program-for-nth-fibonacci-number/">Fibonacci number</a> with n &gt;= 1. Fibonacci Sequence is 0, 1, 1, 2, 3, 5, 8,13,… (here 0 is the 0th Fibonacci number).</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 1
<strong>Output:</strong> 1
<strong>Explanation:</strong> f(n+1)*f(n-1) - f(n)*f(n) = 1*0 - 1*1 = -1.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> n = 2
<strong>Output:</strong> 1
<strong>Explanation:</strong> f(n+1)*f(n-1) - f(n)*f(n) = 2*1 - 1*1 = 1.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematical</code>&nbsp;<code>Fibonacci</code>&nbsp;
