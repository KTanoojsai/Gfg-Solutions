<h2><a href="https://www.geeksforgeeks.org/problems/the-mighty-divisible-number22312231/1?page=8">Mighty Divisor</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given four integers <strong>a</strong>, <strong>b</strong>, <strong>c</strong> and <strong>n</strong>, find the smallest n-digit number that is divisible by all three numbers a, b, and c. </span><span style="font-size: 18px;">If no such n-digit number exists, return -1.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a = 2, b = 3, c = 5, n = 2
<strong>Output:</strong> 30
<strong>Explaination: </strong></span><span style="font-size: 18px;">The LCM of 2, 3, and 5 is 30. It is the smallest 2-digit number divisible by all three numbers.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a = 3, b = 5, c = 7, n = 2
<strong>Output:</strong> -1
<strong>Explaination:</strong> The LCM of 3, 5, and 7 is 105, which is a 3-digit number. Hence, there is no 2-digit number divisible by all three numbers.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ a, b, c ≤ 1000<br>1 ≤ n ≤ 9</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>number-theory</code>&nbsp;<code>Mathematical</code>&nbsp;<code>Numbers</code>&nbsp;<code>Division</code>&nbsp;
